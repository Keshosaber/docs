## Mintlify component reference

### Callout components

Use the appropriate callout for each situation:

- `<Note>` — Supplementary information that supports the main content
- `<Tip>` — Expert advice, shortcuts, or best practices
- `<Warning>` — Critical information about potential issues or breaking changes
- `<Info>` — Background information or neutral announcements
- `<Check>` — Positive confirmations or successful completions

### Code components

- Use fenced code blocks with language tags for syntax highlighting
- Use `<CodeGroup>` for showing the same concept in multiple languages
- Include complete, runnable examples with realistic data
- Use `<RequestExample>` and `<ResponseExample>` for API endpoint documentation

### Structural components

- `<Steps>` — Sequential instructions and procedures
- `<Tabs>` — Platform-specific content or alternative approaches
- `<Accordion>` / `<AccordionGroup>` — Progressive disclosure of information
- `<Card>` / `<CardGroup>` — Highlighting and linking to content
- `<Frame>` — Wrapping images with descriptive alt text

### API documentation components

- `<ParamField>` — Document API parameters with type, required status, and description
- `<ResponseField>` — Document API response fields
- `<Expandable>` — Nested object properties or hierarchical information
